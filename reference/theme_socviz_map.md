# theme_socviz_map

Socviz map theme

## Usage

``` r
theme_socviz_map()

theme_socviz_kjh_map()
```

## Details

You should \[import_socviz_condensed\]() and \[import_socviz_semi\]()
first and also install the fonts on your system before trying to use
this theme.
